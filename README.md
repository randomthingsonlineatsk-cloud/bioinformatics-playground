# Bioinformatics Playground

Everyday sequence and lab maths in one browser tool.

**Live demo:** https://bioinformatics-playground.randomthingsonlineatsk.workers.dev

> This is a fictional, educational demonstration. Do not use it for real patient data, clinical decisions or regulatory submissions.

## Features
- DNA analysis: GC%, melting temperature (Tm), reverse complement
- Six-frame translation with ORF finding
- Protein mass calculator
- Sample-size calculator and randomisation lists
- Runs entirely in your browser; nothing you type is sent anywhere

## Tech stack
TanStack Start (static prerender), React, Tailwind CSS. Hosted on Cloudflare Workers; tested with Vitest.
